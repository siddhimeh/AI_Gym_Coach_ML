# Data Directory

This directory stores raw video clips, licensing metadata, and processed landmark datasets for the AI Gym Coach project.

## Video Clips (`data/clips/`)

### 1. `squat_sample.webm`
- **Class / Form**: `good` (Full-depth bodyweight squat).
- **Source**: [Wikimedia Commons - File:Squat - exercise demonstration video.webm](https://commons.wikimedia.org/wiki/File:Squat_-_exercise_demonstration_video.webm) (Original by *FitnessScape*).
- **License**: Creative Commons Attribution 3.0 Unported (CC BY 3.0).
- **Frames**: 213 frames, 30 FPS.
- **Biomechanical Profile**: Knee angle reaches $55.7^\circ$ at bottom; back lean remains upright at $\approx 17.9^\circ$.

### 2. `squat_shallow_rep.webm`
- **Class / Form**: `too_shallow` (Prescribed half squat with incomplete depth).
- **Source**: Extracted from [Wikimedia Commons - File:Muscle Strengthening at Home - Half squat.webm](https://commons.wikimedia.org/wiki/File:Muscle_Strengthening_at_Home_-_Half_squat.webm) (CDC Home Strengthening Program).
- **License**: Public Domain / Creative Commons.
- **Frames**: 117 frames, 29.97 FPS.
- **Biomechanical Profile**: Knee angle bottoms out at $130^\circ - 135^\circ$ (stops short of parallel).

## Processed Dataset (`data/processed/squat_dataset.csv`)
- **Generated by**: [`ml/build_dataset.py`](../ml/build_dataset.py)
- **Schema**:
  - `clip`: Source clip identifier
  - `frame`: Frame index within clip
  - `knee_angle`: Knee interior angle (Hip-Knee-Ankle) in degrees
  - `hip_angle`: Hip hinge angle (Shoulder-Hip-Knee) in degrees
  - `back_lean`: Torso tilt from vertical (Hip-Shoulder vs. vertical) in degrees
  - `confidence`: MediaPipe landmark visibility confidence
  - `side`: Camera-facing active side (`left` / `right`)
  - `phase`: `standing`, `transition`, or `inflection`
  - `label`: `standing`, `good`, `too_shallow`, or `back_leaning_forward`
  - `is_augmented`: Boolean flag denoting whether the row is real video capture or simulated kinematic augmentation

### Data Limitations & Academic Honesty (Viva Reference)
- Public exercise libraries typically only demonstrate correct technique or half-squats. Open-source recordings of dangerous or excessive back rounding are scarce.
- To provide training data for all 3 project targets, 60 samples for `back_leaning_forward` were generated via kinematic simulation (back lean $> 42^\circ$) and explicitly flagged in `is_augmented`.
